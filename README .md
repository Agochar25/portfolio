Personal portfolio of **Agochar Mahajan**, B.Tech Computer Science & Engineering student at SRM Institute of Science and Technology, focused on designing and building AI-powered products.

## What's inside

- **Approach** – how I think about AI and the people using it
- **At a glance** – key numbers and strengths
- **Role fit** – how my projects map to an AI Generalist (Design) role
- **Selected work** – ProxyPortal, PennyAI, HaqDaar-AI, VeriClaim-AI, Wellness Spot, LinkPulse
- **Toolkit** – UI, AI/ML, back end, cloud and DevOps
- **Journey** – AWS certifications and education
- **Contact**

## Built with

A single, dependency-free `index.html`: hand-written HTML, CSS and JavaScript, with Google Fonts. Features include a live particle-field hero, a speedometer-style profile cluster, an auto-sliding project carousel with grid view, scroll-triggered reveals, five colour themes and a ⌘K / Ctrl+K quick-navigation palette.

## Run locally

Open `index.html` in any modern browser. No build step is needed.
